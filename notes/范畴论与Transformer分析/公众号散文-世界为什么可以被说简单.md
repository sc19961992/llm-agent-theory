# 世界那么复杂，规律为什么可以很简单？

## 一个关于状态、压缩与涌现的故事

很久以前，一座临河的城里住着两位记录员。

第一位记录员每天沿河行走，把见到的一切写进档案：每一朵浪花的位置，每一块石头的颜色，每一片落叶打了几个旋。几年以后，他的档案堆满整座仓库。城里人问他明天会不会涨水，他说，还需要再核对昨天下午第三千七百二十一朵浪花的形状。

第二位记录员只在木板上画三个符号：低水、平水、高水。他观察上游的雨、河面的高度和水流的速度，再记录三个符号之间通常怎样变化。他的记录远不如第一位详细，却能提醒人们什么时候收起渡船，什么时候关闭桥洞。

谁更懂这条河？

第一位保存了更多事实，第二位找到了更有用的状态。所谓状态，并不一定是世界自身贴好的标签。它可以是我们为了分辨经验、组织记忆和预测变化而作出的划分。河水没有说自己处于“高水状态”，但这个符号能把大量不同的浪花归到同一种与防洪有关的情形中。

本文采取一种操作主义的认识论立场：人能够表达和检验的规律，基于对经验现象的区分与标记。状态是对可区分经验情形的符号表示，规律是这些状态之间经过经验校验的概率关系，形式逻辑负责组织这些关系并导出可检验的预测。

这并不是说世界只是语言，也不是说随便贴几个标签就能创造规律。标签必须经受经验检验。把河水分成“漂亮”“不漂亮”，通常无法预测洪水；把它分成低水、平水和高水，则可能保留防洪所需要的信息。标签有没有价值，取决于它是否保留了我们关心的现象，以及仅凭这些标签能否继续预测变化。

## 一杯水为什么不需要一部宇宙史

桌上的一杯热水，包含难以计数的分子运动。若想逐一记录每个分子的位置和速度，描述会比日常经验中的“这杯水正在变凉”复杂得多。

但在许多条件下，我们只需要温度、压力、体积等少量宏观量。大量不同的分子排列可以具有相同温度，而相同温度的水，在相似环境中又会以相近方式继续变化。于是，“温度”不只压缩了描述，还保留了预测能力。

这里有两个缺一不可的动作。

第一个动作是简化：把许多微观情形归入少数宏观状态。

第二个动作是闭合：当两个微观情形被归入同一宏观状态后，它们下一步落入各宏观状态的概率也应当足够接近。这样，我们才可以暂时放下分子细节，仅根据温度预测温度。

只有简化，没有闭合，得到的只是一个省字的分类法；既能简化，又能近似闭合，才得到一个能够自行演化的宏观规律。

在这一认识论框架下，本文证明：对于规模有限的复杂系统，如果微观层面的某部分规律能够在保留所关心现象及其变化关系的前提下，用更少的宏观符号重新表达，而且仅根据这些宏观符号就能近似预测下一步变化，那么在给定误差范围内，必然存在一种使用符号最少的宏观规律。它能够脱离微观细节，独立描述和预测这部分变化，真实误差具有明确上界。

这句话真正增加的内容，不是“有规律的地方存在规律”，而是“只要至少存在一种合格的简化，就能在全部合格简化中找到最省状态的一种”。对于有限系统，候选的状态划分虽然可能多得无法枚举，却仍是有限的；只要可行集合不是空的，状态类别数的最小值就一定能够达到。

这里的“最简单”有严格边界。它指在所关心的现象和给定的一步误差标准下，需要区分的宏观状态类别最少。它不自动等于公式最短、参数最少、计算最快，也不保证人们能够高效找到它。

## 城市为什么能变成一张红黄绿的图

早高峰的城市里，每辆车都有自己的目的地、速度和驾驶习惯。如果导航系统必须理解每位司机的一生，才能判断前方是否拥堵，它就永远来不及给出路线。

现实中的交通图把这些细节压缩成少数颜色和速度区间：畅通、缓行、拥堵。两段道路即使车辆组成完全不同，只要当前的流量和速度相近，其下一时刻的交通状态就可能具有相似分布。导航不必复现每辆车，只需预测这些宏观状态如何传播。

当然，红黄绿并不总是足够。球赛散场、道路施工、暴雨和事故会让原有分类失效。此时不是“宏观规律不存在”，而是当前状态标签遗漏了影响下一步的重要信息。我们可以加入天气、事件或道路封闭状态，也可以承认误差上升。

这正是误差上界的意义：宏观规律不是被宣布为绝对正确，而是要说明它在什么环境、什么任务和什么时间尺度上有效，以及偏离真实系统最多有多大。

## 牧羊人没有给每一朵云起名字

还有一个更古老的故事。

一个年轻人问牧羊人：“天上的云每一朵都不同，你怎么知道要下雨？”

牧羊人说：“我不需要记住每一朵云。我只记得，哪几种天色之后，羊会靠近山脚；哪几种风之后，石头很快会变湿。”

年轻人又问：“那你记住的就是真正的云吗？”

牧羊人回答：“不是。我记住的是对回家有用的云。”

这则寓言点出了规律的任务相对性。同一个世界可以有许多正确的宏观划分。气象学家、飞行员、摄影师和牧羊人面对同一片天空，所需状态并不相同。不存在脱离一切关切、对所有问题都唯一最简的宏观规律。定理讨论的是：当所要保留的现象与允许误差已经确定后，最简的可行规律是否存在。

## Transformer 也在面对同一条河

一个 Transformer 的底层情形极其庞大：网络架构和参数决定计算方式，输入 token、位置、隐藏状态和 KV cache 共同构成一次生成的具体历史。若把每段不同历史都看成完全不同的情形，语言生成几乎没有可以复用的规律。

然而，人类语言的许多预测并不需要恢复全部微观计算。比如一句话是在提问还是回答，一个代词正在指向谁，一段程序还缺少哪个括号，一项指令已经执行到哪一步——大量不同的 token 历史，可能具有相同的下一步预测需求。

如果这些与预测有关的语言状态数量远少于完整历史，如果它们能随新 token 递推更新，如果 Transformer 确实学会了相应的下一 token 分布，而且这些状态能够由它的完整推理状态确定，那么这些语言状态就构成一个近似闭合的宏观表示。我们可以只根据当前语言状态预测下一 token，并更新到下一个语言状态，而不必在宏观描述中逐项复述全部参数活动。

这给出了 Transformer 涌现语言规律的一种条件性解释：宏观语言状态不是凭空出现的神秘实体，而是生成行为中可压缩、可递推、可检验的预测等价类。

但这个结论不等于“任何训练成功的 Transformer 内部都自动形成低维流形”。行为上存在低复杂度的预测状态，与这些状态能否从某层 hidden states 或 KV cache 中稳定读出，是两个层次的问题；要进一步声称神经激活位于低维流形，还需要额外的几何和鲁棒性条件。

## 最简单的规律，不一定最容易找到

想象一座拥有许多房间的迷宫。我们已经知道其中至少有一条从入口通向出口的短路，并且所有房间数量有限。于是，最短路线一定存在。这并不意味着闭上眼就能找到它，也不意味着它只有一条。

宏观规律也是如此。

定理保证的是存在与达到：只要符合要求的压缩表示已经存在，状态类别最少的可行表示就存在；固定一种表示后，使闭合误差最小的宏观转移规律也存在。

定理没有保证发现与计算：候选划分可能多得惊人，最优规律可能不唯一，训练算法也可能停在更复杂的表示上。理论告诉我们山顶确实存在，却没有自动修好登山的路。

因此，这个结论对工程最直接的启示，不是等待规律自己显现，而是寻找三类证书：哪些信息必须为目标保留，哪些微观差异可以被忽略，哪些宏观状态能够在下一步预测中近似闭合。守恒量、对称性、预测状态和稳定的可读出表征，都是可能的线索。

## 我们用有限的词，接近复杂的世界

人类从来没有携带世界的完整副本生活。

我们说冷暖，不逐个追踪空气分子；说涨落，不记录每一朵浪花；说拥堵，不讲述每一位司机；说语义，也不会复述神经网络中每一次乘加运算。我们不断把经验压缩成状态，再用状态之间经受过检验的关系预测下一刻。

压缩可能丢失细节，所以规律有适用范围；预测可能出现偏差，所以规律需要误差；环境可能改变，所以规律必须继续接受经验检验。宏观规律的力量从来不在于消灭复杂性，而在于证明：对于我们关心的变化，有些复杂性可以暂时不被携带。

如果复杂系统的一部分运行规律能用更少的宏观符号表达，而且仅靠这些符号就能继续预测变化，那么一定存在一种符号最少、能够独立预测且误差有明确上限的宏观规律。

世界仍然复杂。真正的发现，是找到一种足够少的语言，让复杂世界的下一步仍然可以被说出。
