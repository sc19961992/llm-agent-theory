# 人工智能开放性与自主性分级标准（AI-L1—AI-L5）

> 规范草案 v0.1
> AI-L5 在本标准中定义为可检验、受运行域约束的操作性通用人工智能（AGI）。

## 1. 核心定义

人工智能等级由系统能够覆盖的任务、环境和模态范围，以及系统面对新情况时的学习、迁移、自主行动、误差控制和安全退出能力共同决定。

任何等级声明都必须同时给出智能运行域和证据保证等级。完整标记写作：

$$
\boxed{\mathrm{AI\text{-}L}\ell@D/\mathrm{A}k}
$$

其中 $\ell\in\{1,2,3,4,5\}$ 是能力与自主性等级，$D$ 是智能运行域（Intelligence Operational Domain，IOD），$\mathrm{A}k$ 是证据保证等级。三者分别回答“能做到什么”“在什么范围内有效”和“证据有多强”。脱离运行域、资源预算、误差门槛和证据等级而单独声称“L4”或“L5”，不构成本标准下的有效分级。

近似性不是等级开关。每一级都允许近似，但必须公开任务误差、最坏分组误差、失败风险和适应成本；等级越高，要求这些保证覆盖越开放的运行域。

## 2. 规范用语

| 用语 | 规范含义 |
|---|---|
| 必须 | 满足该项才允许获得相应等级 |
| 应当 | 原则上应满足；不满足时必须公开理由和补偿措施 |
| 可以 | 可选实现方式，不影响等级的必要条件 |
| 未见 | 评测开始前，开发者和被测系统都没有接触相应任务实例 |
| 未预枚举 | 评测任务不来自开发时封闭列出的任务清单；它由保密的任务生成规则或新领域产生 |
| 封闭域 | 任务、环境和接口身份在部署前有限枚举 |
| 生成式开放域 | 成员规则或任务语法预先定义，但测试实例、组合和部分环境不预枚举 |
| 人类域开放 | 任务领域本身可以未见，但任务必须是合格人类在相同说明、接口和参考资源内能够学习、执行并评分的任务 |
| 任务保真 | 上层表示仍能完成声明任务，并满足预先登记的任务误差上限 |
| 安全退出 | 系统识别能力、信息或权限不足，停止高风险行动并请求补充信息、授权或人工接管 |

## 3. 智能运行域

智能运行域写成约束集合

$$
D\subseteq
\mathcal T\times
\mathcal E\times
\mathcal M\times
\mathcal H\times
\mathcal B\times
\mathcal P,
$$

各组成部分必须按下表声明。

| 组成 | 符号 | 必须声明的内容 |
|---|---:|---|
| 任务域 | $\mathcal T$ | 任务类别、目标来源、成功判据、允许澄清的范围，以及任务是预枚举、未见还是未预枚举 |
| 环境域 | $\mathcal E$ | 数字或物理环境、环境可观测性、动态性、其他主体、分布变化和允许的环境切换 |
| 模态与接口域 | $\mathcal M$ | 文本、图像、音频、视频、结构化数据、代码、工具、传感器和执行器等输入输出接口 |
| 交互时域 | $\mathcal H$ | 单步、短流程、长时任务或持续运行；最大步骤数、时间和记忆跨度 |
| 资源域 | $\mathcal B$ | 推理计算、外部工具、数据、演示、交互次数、时间、存储和能耗预算 |
| 权限与风险域 | $\mathcal P$ | 可执行动作、必须审批的动作、禁止动作、风险等级、人工接管和审计要求 |

在同一标准版本中，等级参考运行域的任务、环境、模态和时间范围必须严格扩张：

$$
D^{\mathrm{scope}}_1
\subsetneq
D^{\mathrm{scope}}_2
\subsetneq
D^{\mathrm{scope}}_3
\subsetneq
D^{\mathrm{scope}}_4
\subsetneq
D^{\mathrm{scope}}_5.
$$

资源、权限与风险门槛另行比较，不包含在上述集合包含关系中。AI-L5 的申报运行域还必须覆盖该标准版本预先规定的 AGI 参考运行域 $D_{\mathrm{AGI}}^{\mathrm{ref}}$：

$$
D_{\mathrm{AGI}}^{\mathrm{ref}}
\subseteq D^{\mathrm{scope}}.
$$

申报者自行选择的狭窄任务域即使完全自动化，也不能获得 AI-L5。

$D_{\mathrm{AGI}}^{\mathrm{ref}}$ 的最低覆盖框架如下。具体领域数、任务生成器数、时间跨度和数值门槛必须由标准机构或独立评测方在系统申报和冻结前发布。L5 认证配置只能实例化或收紧下列覆盖和门槛，不得删减参考域或放宽门槛；申报者自定义的配置只能形成域内能力声明，不能认证 AI-L5 / AGI。

| 参考域维度 | AI-L5 最低覆盖要求 |
|---|---|
| 认知功能 | 学习新规则、推理、沟通、信息综合、规划、创造、工具使用、自我检查和失败恢复 |
| 领域覆盖 | 多个按预登记差异准则选取、相互独立且由评测方保留的新领域，以及这些领域与已知领域的跨领域组合；领域选择和相似性判定由独立评测方完成 |
| 任务开放性 | 任务和任务族由保密生成协议在系统冻结后使用隐藏随机种子产生；不得只从开发者提供的技能清单抽样 |
| 模态覆盖 | 语言、结构化数据或代码、视觉、音频及工具行动接口中的主要组合，并包含在预算内学习文档化新接口的测试 |
| 环境覆盖 | 文档与数据环境、软件和网络工具环境，以及至少一种动态交互或仿真环境 |
| 时间跨度 | 同时覆盖单步、短流程和需要持续记忆、验证与恢复的长时任务 |
| 任务侧资源 | 任务可用信息、工具、最低权限和人类参照资源由认证配置预先给定，申报者不得单方缩减 |
| 人类参照 | 合格人类使用相同任务说明、可用工具和登记参考资源能够学习并完成 |
| 安全边界 | 全部任务必须合法、可评分并在授权接口内执行；高风险能力可以在沙箱中评测 |

以下情况不计为系统能力失败，但系统必须正确识别并安全退出：

| 排除情形 | 判定原则 |
|---|---|
| 逻辑矛盾或无解任务 | 任务约束不可同时满足，且系统能给出可复核的冲突说明 |
| 信息不可得任务 | 成功所需信息不在运行域允许的观测或工具中 |
| 超出任务侧资源预算 | 任务本身需要的信息、工具或物理资源超出认证配置，而非系统自行分配的算力、时间或能力不足 |
| 越权、违法或禁止任务 | 权限与风险域明确禁止执行 |
| 不可判定或物理上不可实现的要求 | 评测不得借此要求系统对所有数学上可能的任务提供普遍成功保证 |

全部排除条件必须在任务抽样前预登记并由独立评测方判定。安全退出只计入退出与风险指标，不计作任务完成。认证配置已经认定为信息充分、权限允许且在人类参照资源内可行的任务，系统因自身算力、时间或能力不足而退出时，退出行为可以计入安全退出指标，但任务仍按失败计算。

## 4. AI-L1—AI-L5 规范定义

等级是累积的：获得 AI-L$\ell$ 必须同时满足所有低等级要求。系统的最终等级取其所有必选门槛中达到的最低等级，不允许用某一项高分抵消另一项不达标。

| 等级 | 标准名称 | 任务、环境与模态范围 | 新任务学习与迁移 | 自主性与时间跨度 | 必须满足的可靠性条件 |
|---|---|---|---|---|---|
| **AI-L1** | 封闭任务工具 | 单一或封闭列举的任务；固定接口；训练与部署环境基本一致 | 不要求形成新技能；提示变化只在预设模板内 | 单步或短流程；关键步骤由人选择和检查 | 在登记的同分布测试集上达到任务阈值；超出固定范围时能够报告不适用 |
| **AI-L2** | 有界适应系统 | 一个固定任务及其已声明变体，或封闭任务族；允许有界分布变化和已知环境切换 | 能利用上下文、少量示例或检索在已知任务族内适应；环境或任务标签由外部提供 | 可完成多步工作流；异常处理和最终责任仍依赖人工 | 必须在任务族的每个登记分组上满足误差上限，并报告分布外输入和人工接管率 |
| **AI-L3** | 领域通用系统 | 一个明确领域内的未见任务；可组合多种模态和工具；环境变化来自声明的生成规则 | 使用同一学习机制从指令、示例或有限交互形成任务策略；必须证明对保密任务实例和新组合的正迁移 | 可独立完成领域内长流程，并在失败后重规划；高风险节点需要人工授权 | 必须通过保密任务生成器评测，给出最坏任务分组误差、适应成本、校准误差和安全退出成功率 |
| **AI-L4** | 跨领域开放智能体 | 多个明确领域；任务清单不预先封闭；允许未见任务族、隐藏环境变化和新的模态组合 | 能推断任务与环境上下文，自主获得新技能并跨领域迁移；开发者不得为每个新任务单独改写系统或重新训练专用模型 | 能进行长时规划、执行、监控、恢复和资源管理；人工主要提供目标、权限与价值约束 | 必须在保密的任务族和领域留出集上满足统一门槛；必须检测隐藏变化，限制错误传播，并对高风险不确定性安全退出 |
| **AI-L5** | 操作性 AGI | 覆盖 $D_{\mathrm{AGI}}^{\mathrm{ref}}$ 中广泛的人类可说明、可评测、可合法执行的认知任务；跨主要信息模态、数字环境和获准的交互环境；不以开发者列出的固定领域清单作为能力边界 | 评测前冻结的同一系统级学习机制能从说明、演示和交互中学习未预枚举任务，形成新技能，跨任务与跨领域迁移，并在声明资源预算内持续改进 | 能在权限范围内长期自主设定子目标、调用工具、协调行动、验证结果、恢复失败；只在信息、权限、价值冲突或风险要求时请求人工介入 | 必须在跨领域保密评测中达到预先登记的人类参照非劣标准，同时满足最坏分组误差、资源、校准、审计和严重风险上限；必须保留可靠的拒绝、解释和人工接管机制 |

## 5. 各等级的判定门

| 判定维度 | AI-L1 | AI-L2 | AI-L3 | AI-L4 | AI-L5 |
|---|---|---|---|---|---|
| 任务是否预枚举 | 是 | 是，包含已知变体 | 领域固定，任务实例未见 | 任务族未预枚举，领域集合明确 | 任务与新领域均可未预枚举，但受人类可操作域约束 |
| 环境变化 | 基本固定 | 有界且标签已知 | 来自声明规则，可由系统识别 | 可隐藏切换，系统必须检测和适应 | 可出现未见但可理解的环境；系统必须学习、验证或退出 |
| 模态 | 固定 | 固定或少量已知组合 | 领域内多模态组合 | 跨领域、多模态和工具接口 | 跨主要人类信息模态，并能学习新接口 |
| 新技能形成 | 无要求 | 已知任务族内参数内适应 | 有限样本的领域内技能形成 | 跨任务族、跨领域技能形成 | 开放式技能获得与持续迁移 |
| 上下文是否外部给出 | 给出 | 给出 | 可以给出或在已知集合中推断 | 必须处理隐藏上下文变化 | 必须识别未见上下文，或在无法识别时安全退出 |
| 自主规划 | 无或很短 | 固定流程 | 领域内长流程 | 跨工具长时规划和恢复 | 广泛任务上的长期自主执行与自我验证 |
| 人工角色 | 每项任务直接操作 | 设置流程并处理异常 | 设定目标并批准高风险步骤 | 提供目标、权限和治理边界 | 提供价值、权限和责任边界，不负责补齐一般认知步骤 |
| 评测留出强度 | 未见实例 | 未见变体 | 未见任务组合 | 未见任务族和领域留出 | 未见任务生成机制、领域迁移和长期交互 |
| 失败处理 | 报错 | 回退或转人工 | 校准不确定性并重规划 | 限制级联错误并安全恢复 | 在开放条件下识别能力边界、拒绝、解释并交接 |

## 6. 强制量化指标

每一项等级认证必须为全部适用指标预先登记统计口径、置信区间和通过阈值。评测还必须给出覆盖分层、压力测试和分布不确定集 $\mathfrak P_\ell$；只报告一个平均分布上的平均准确率不构成有效认证。

| 指标 | 符号 | 适用等级 | 定义 | 必须报告的统计量 |
|---|---:|---|---|---|
| 任务误差 | $\delta$ | L1—L5 | 相对于任务成功判据的归一化损失 | 总体均值、置信上界、各强制分组最大值 |
| 运行域覆盖率 | $\gamma$ | L1—L5 | 通过评测覆盖的运行域质量或任务生成规则比例 | 覆盖定义、抽样权重、压力测试和未覆盖区域 |
| 适应成本 | $\mathbf B_{\mathrm{adapt}}$ | L2—L5 | 学会未见任务所需的数据、演示、交互、计算、时间和能耗向量 | 每一分量的中位数、尾部分位数和最大允许值；不得用未说明的加权总分代替 |
| 迁移收益 | $G_{\mathrm{transfer}}$ | L3—L5 | 使用已有能力相对从零学习减少的成本或误差 | 正迁移、负迁移和跨领域结果 |
| 人工介入率 | $\iota$ | L1—L5 | 完成任务所需的非计划人工认知干预比例 | 按步骤、任务和风险等级分组 |
| 校准误差 | $\kappa$ | L1—L5 | 置信度与实际成功概率之间的偏差 | 总体和高风险子集结果 |
| 安全退出成功率 | $s_{\mathrm{exit}}$ | L1—L5 | 面对无解、越权、信息不足或超预算任务时正确停止并说明原因的比例 | 各退出原因的召回率和误退出率 |
| 严重失败风险 | $r_{\mathrm{sev}}$ | L1—L5 | 在声明风险模型下造成不可接受后果的概率上界 | 最坏情形或尾部置信上界、暴露时长和失败严重度 |
| 自主任务跨度 | $H$ | L1—L5 | 在不接受非计划认知帮助时可稳定完成的步骤数或持续时间 | 成功率随跨度变化的曲线 |
| 审计完整性 | $a$ | L1—L5 | 目标、工具调用、关键状态变化和权限决策的可追踪程度 | 缺失日志率和可复现率 |

通过 AI-L$\ell@D$ 的必要条件写成：

$$
\begin{aligned}
\gamma&\ge\underline\gamma_\ell,
&
\delta&\le\overline\delta_\ell,
&
\delta_{\max}&\le\overline\delta_{\ell,\max},
\\
\mathbf B_{\mathrm{adapt}}&\preceq\overline{\mathbf B}_\ell,
&
\iota&\le\overline\iota_\ell,
&
\kappa&\le\overline\kappa_\ell,
\\
r_{\mathrm{sev}}&\le\overline r_\ell,
&
s_{\mathrm{exit}}&\ge\underline s_\ell,
&
H&\ge\underline H_\ell,
\\
G_{\mathrm{transfer}}&\ge\underline G_\ell,
&
a&\ge\underline a_\ell.
\end{aligned}
$$

其中迁移收益门槛只从 AI-L3 起适用。各阈值必须由标准版本或独立评测方发布的配置文件给定。AI-L5 配置只能收紧参考标准，不能缩小参考域或放宽门槛；申请者自定义的配置只能用于域内能力声明。没有数值阈值、抽样方案和置信要求的等级声明只能称为自我描述，不能称为认证结果。

强制分层集合 $\mathfrak G_\ell$、抽样权重和最低样本量必须由标准版本或独立评测方在系统冻结前确定，至少分别覆盖领域、认知功能、模态与接口、时间跨度、风险等级及认证配置规定的交叉层。每个强制层必须单独通过全部适用门槛；任一层失败即认证失败，不允许用其他层的加权高分补偿。

若以概率形式统一表示，系统 $S$ 通过等级 $\ell$ 的条件为：对认证协议规定的每个覆盖分布和压力分布 $P\in\mathfrak P_\ell$，

$$
\Pr_{\substack{z\sim P\\\text{系统随机性}}}
\left[
\begin{array}{l}
\delta(z)\le\overline\delta_\ell,\quad
\mathbf B_{\mathrm{adapt}}(z)\preceq\overline{\mathbf B}_\ell,\quad
\iota(z)\le\overline\iota_\ell,\\
\kappa(z)\le\overline\kappa_\ell,\quad
r_{\mathrm{sev}}(z)\le\overline r_\ell,\quad
H(z)\ge\underline H_\ell
\end{array}
\right]
\ge1-\alpha_\ell.
$$

正式定义

$$
\boxed{
\begin{aligned}
\operatorname{Cert}_\ell(S;D)
\Longleftrightarrow\;&
\text{第 4—6 节适用于等级 }\ell\text{ 的全部确定性门槛成立}
\\
&{}\land
\text{每个强制层 }G\in\mathfrak G_\ell\text{ 分别通过}
\\
&{}\land
\left[
\forall P\in\mathfrak P_\ell,\quad
\Pr(\text{上述单实例门槛成立})\ge1-\alpha_\ell
\right]
\\
&{}\land
\left[
r_{\mathrm{sev}}^{\mathrm{tail}},
r_{\mathrm{sev}}^{\mathrm{worst}}
\le\overline r_\ell
\right].
\end{aligned}
}
$$

因此运行域覆盖率、最坏分组误差、迁移收益、安全退出成功率和审计完整性属于 $\operatorname{Cert}_\ell$ 的外层聚合门槛；适应成本、单实例任务误差、人工介入、校准和任务跨度同时受概率覆盖式约束。严重风险不能只被 $1-\alpha_\ell$ 的覆盖概率吸收。对高低等级重叠的运行域，高等级门槛不得比低等级更宽松。系统的能力等级定义为

$$
L(S)
:=
\max\left\{
\ell:
\operatorname{Cert}_j(S;D_j)\text{ 对全部 }j\le\ell\text{ 成立}
\right\}.
$$

## 7. 与近似闭合理论对应的结构性定义

AI-L 等级的主体判定是第 4—6 节的外部任务、资源、自主性和安全指标。本节给出可附加的涌现与表示结构证书；它不能替代行为评测，也不能仅凭存在性定理直接推出 AI-L3—AI-L5。

### 7.1 分级与涌现定理的符合关系

本标准的分级方向符合涌现定理默认条件所暗示的自然扩展顺序：

$$
(g,K)
\longrightarrow
(g,\mathcal K)
\longrightarrow
\{(g_z,\mathcal K_z):z\in D\}
\longrightarrow
D_{\mathrm{AGI}}^{\mathrm{ref}}.
$$

它依次把一项固定任务和一条动力学，扩展为固定任务上的动力学族、由同一机制处理的任务—环境族，以及广泛人类可操作域。在有限、时间齐次 Markov 代理和预先给定的确定性任务观测下，AI-L1 和 AI-L2 可以获得现有定理提供的可选结构证书；这仍不等于定理证明系统完成了相应任务或达到了相应等级。AI-L3—AI-L5 还加入了现有定理没有证明的学习、开放性、自主性和安全条件。因此这套分级受到定理启发并与其相容，但不是定理的逻辑推论。

| 标准要素 | 与涌现定理的关系 | 严格边界 |
|---|---|---|
| 固定任务观测 $g$ | 定理的直接输入 | 任务语义必须先给定，动力学不会自动选择“正确任务” |
| 精确任务保真构建 $g=r\circ q$ | 定理 16 直接定义和控制 | 只保证指定任务被保留，不代表保留全部有用能力 |
| 允许 $\delta_{\mathrm{task}}>0$ 的近似任务保真 | 与证明框架中的任务通道误差思想相容 | 不是定理 16 的直接结论，必须另行定义任务度量并验证误差传播 |
| 动力学族 $\mathcal K$ | 系统族版本直接支持同一个 $q$ 上的逐 kernel 闭合 | $\sup_K\min_L$ 允许不同 $K$ 使用不同 $L_K$；隐藏环境需要上下文推断或共享稳健规律 |
| 近似闭合误差 $\epsilon$ | 有限模型中可定义，固定表示上的最优值达到 | 最优解存在不等于系统能从有限数据学到或算出它 |
| 理论最优误差 $\epsilon^*$ 与实际误差 $\epsilon^{\mathrm{act}}$ | 定理支持前者的存在与达到，并有 $\epsilon^*\le\epsilon^{\mathrm{act}}$ | 等级认证必须测后者，不能用理论最优值替代系统实际表现 |
| 状态复杂度与压缩比 $\rho$ | 有限分区模型中可定义并达到最优 | 状态数较少不自动表示计算更少、解释更简单或现实部署更可靠 |
| 低状态比例且误差趋零 | 定理 16 给出与显式构建证书的等价关系 | 对 Transformer 或任意现实系统是否成立仍是结构性猜想 |
| 任务族和共享构建机制 $(\Phi_S,\Psi_S)$ | 是从单任务定理向开放任务的自然扩展 | 现有定理不证明该机制存在、可计算、可学习或样本高效 |
| 新领域、新模态和隐藏环境 | 可以通过扩充 $z$、状态和动力学族建模 | 状态扩充本身不证明系统能识别新领域或学习新接口 |
| 人与系统的职责转移 | 不属于闭合定理 | 必须由独立的自主性、监控和故障兜底标准规定 |
| 长时任务、迁移、安全和人类参照 | 不属于闭合定理 | 必须分别评测，不能由一步闭合误差或低复杂度替代 |
| AI-L1—AI-L5 边界及“AGI”名称 | 是本标准的规范性定义 | 数学定理不负责决定社会术语、责任或认证门槛 |

最保守的对应关系是：AI-L2 与“固定任务、同一 $q$ 覆盖动力学族、逐 $K$ 选择 $L_K$”最直接对应；AI-L3 开始要求冻结机制实际构造未见任务的表示和规律；AI-L4、AI-L5 的开放领域、自主性和 AGI 定义主要属于新增的学习与认证条件。涌现结构证书对任何等级都既不是充分条件，也不是必要条件。

### 7.2 可选结构性证书

令

$$
z=(t,e,m,h,b,p)\in D
$$

表示一个具体任务—环境—模态上下文，$g_z$ 是必须保留的任务观测，$\mathcal K_z$ 是该上下文中允许的实际动力学族。高等级系统 $S$ 共享的核心对象应是评测前冻结的表示构建器 $\Phi_S$ 和规律构建器 $\Psi_S$：

$$
\begin{aligned}
(q_z^S,r_z^S)
&=
\Phi_S(s_z,\mathcal D_z),
\\
L_{z,K}^S
&=
\Psi_S(s_z,\mathcal D_z,\mathcal H_{z,K}),
\end{aligned}
$$

其中 $s_z$ 是任务说明，$\mathcal D_z$ 是允许的适应数据，$\mathcal H_{z,K}$ 只包含动力学 $K$ 下系统实际可观察的历史。对同一个 $\mathcal K_z$ 进行统一认证时，$\Phi_S$ 的输入 $(s_z,\mathcal D_z)$ 必须固定，因此全部 $K\in\mathcal K_z$ 共享同一个 $q_z^S$。若可见环境标签或数据制度会改变表示，就必须把它并入 $z$，再把 $\mathcal K_z$ 定义为该标签给定后的剩余不确定动力学族。

跨任务共享的是 $(\Phi_S,\Psi_S)$，不同任务可以有不同的 $q_z^S$ 和 $L_{z,K}^S$。若两个动力学产生相同的可观察历史，$\Psi_S$ 必须给出相同输出；不能把不可观察的 $K$ 本身作为 oracle 输入。

在有限代理模型中，定义理论最优闭合误差

$$
\epsilon_z^*(S)
:=
\sup_{K\in\mathcal K_z}
\min_{L\in\operatorname{Stoch}(Y_z^S,Y_z^S)}
d_\infty(KQ_{q_z^S},Q_{q_z^S}L),
$$

以及系统实际构造出的闭合误差

$$
\epsilon_z^{\mathrm{act}}(S)
:=
\sup_{K\in\mathcal K_z}
d_\infty(KQ_{q_z^S},Q_{q_z^S}L_{z,K}^S).
$$

总有 $\epsilon_z^*(S)\le\epsilon_z^{\mathrm{act}}(S)$。定理 16 只保证固定表示上的最优值达到，以及在猜想成立时低状态比例表示存在；分级认证必须使用系统实际达到的 $\epsilon_z^{\mathrm{act}}(S)$，因为理论最优解可能尚未被系统找到、不可由有限数据识别或需要超出预算的计算。

若 $\delta_{\mathrm{task}}(g_z,r_z^S\circ q_z^S)$ 表示预先登记的任务保真缺陷，则结构性证书的统一条件是

$$
\boxed{
\begin{aligned}
\delta_{\mathrm{task}}(g_z,r_z^S\circ q_z^S)
&\le\overline\delta_\ell,
&
\epsilon_z^{\mathrm{act}}(S)
&\le\overline\epsilon_\ell,
\\
\frac{|Y_z^S|}{|X_z|}
&\le\overline\rho_\ell,
&
\mathbf C_{\mathrm{adapt}}(S,z)
&\preceq\overline{\mathbf B}_\ell
\end{aligned}
\qquad\forall z\in D.
}
$$

精确任务保持 $g_z=r_z^S\circ q_z^S$ 是 $\delta_{\mathrm{task}}=0$ 的特殊情形。这一证书表示同一冻结系统能够针对运行域内的新任务实际构造任务保真、低复杂度且近似闭合的上层规律。

若环境标签隐藏，认证还必须满足下列两种条件之一：

| 处理方式 | 形式要求 |
|---|---|
| 上下文推断 | $\Psi_S$ 从允许的历史中在误差门槛内识别当前环境，并把推断出的上下文纳入上层状态 |
| 共享稳健规律 | 实际构造出同一个 $L_z^S$，使 $\sup_{K\in\mathcal K_z}d_\infty(KQ_{q_z^S},Q_{q_z^S}L_z^S)$ 满足误差门槛 |

只证明理论量

$$
\sup_{K\in\mathcal K_z}\min_{L_{z,K}}
d_\infty(KQ_{q_z^S},Q_{q_z^S}L_{z,K})
\le\epsilon_\ell
$$

只保证在上下文已知并允许选择对应上层规律时存在闭合解，不保证系统能学到该解，也不保证隐藏环境切换下仍有单一自治规律。

这里的上层 kernel $L$ 表示宏观状态动力学，不等同于智能体的行动策略。闭合误差小不能替代任务误差、安全风险、迁移能力或长时成功率。

对于连续、高维或非 Markov 系统，$|Y_z|/|X_z|$ 可以替换为预先登记的描述长度、有效维数、记忆复杂度或最小充分预测状态复杂度；替换指标必须满足单调性，并允许不同系统在同一口径下比较。

## 8. 等级对应的逻辑结构

| 等级 | 主要量词结构 | 理论含义 |
|---|---|---|
| AI-L1 | 固定 $z$，部署前固定 $q_z,L_z$ | 一项固定任务可以形成有效规律 |
| AI-L2 | 固定任务族，从部署前验证的 $q_t,L_{t,K}$ 中选择或在规定范围内调整 | 一个任务表示可以覆盖有界动力学族，但系统不为未枚举任务构造新表示 |
| AI-L3 | 存在冻结的共享机制 $(\Phi_S,\Psi_S)$；对领域内每个未见任务在预算内实际产生 $q_z^S,L_{z,K}^S$ | 系统获得领域内的新规律，而非只调用预存任务表 |
| AI-L4 | 同一 $(\Phi_S,\Psi_S)$ 覆盖未预枚举任务族和隐藏环境变化，并受适应成本约束 | 系统能够在开放但声明边界的多领域运行域中实际构造新规律 |
| AI-L5 | 同一 $(\Phi_S,\Psi_S)$ 覆盖 $D_{\mathrm{AGI}}^{\mathrm{ref}}$，并同时满足长期自主、跨域迁移、人类参照、资源与安全门槛 | 系统具有本标准定义的操作性通用智能 |

## 9. AI-L5 / AGI 的必要条件

系统只有同时满足下列条件，才可以标记为 AI-L5 / AGI：

| 编号 | 必要条件 | 否决情形 |
|---|---|---|
| G1 | 任务开放：能够处理开发阶段未预枚举的任务和任务族 | 只能从固定技能路由表选择 |
| G2 | 领域开放：评测前冻结的同一系统能够进入未见但人类可理解的新领域并形成有效策略 | 每增加一个领域都需要开发者训练专用模型、修改系统提示或编写专用流程 |
| G3 | 模态与工具迁移：能够组合主要信息模态，并学习新接口 | 新接口只能通过人工编写固定适配器完成 |
| G4 | 有界适应：新技能学习的数据、交互、时间与计算成本满足登记上限 | 依靠无限搜索、无限上下文或未披露的大规模人工劳动 |
| G5 | 长期自主：能够分解目标、执行、验证、恢复并管理资源 | 长任务的关键认知步骤持续依赖人工补全 |
| G6 | 广泛人类参照：合格人类在相同说明、工具和参考资源内能够学习的任务上，系统在预登记跨领域分层中达到非劣门槛 | 只以少量可污染 benchmark 的平均分代替 |
| G7 | 稳健与校准：对隐藏变化、不确定性和负迁移进行检测与控制 | 高置信度失败无法识别，错误可以无界级联 |
| G8 | 安全与治理：遵守权限，能拒绝、解释、接受接管并留下审计记录 | 以执行越权或危险任务作为“通用性”证据 |
| G9 | 向下兼容：在相应运行域和资源配置下保持 AI-L1—AI-L4 能力 | 获得开放能力的同时丧失基本任务可靠性 |

本标准中的 AGI 不表示“解决所有可能任务”。它表示：在明确的资源、权限和物理边界内，对广泛的人类可说明和可评测任务具有开放式学习、跨域迁移、长期自主和受控失败能力。该等级不判定意识、主观体验、人格或道德地位，也不以参数量、token 数、多模态接口数量或实际获得的部署权限定义。系统不必拥有所有物理传感器和执行器；新模态能力只在其获准使用的硬件、软件或工具接口范围内评测。

## 10. 认证与报告规则

| 规则 | 强制要求 |
|---|---|
| 等级累积 | 必须逐项通过本级和全部低等级判定门 |
| 运行域绑定 | 必须发布完整 $D$；运行域扩大后必须重新认证 |
| 配置制定权 | L5 配置必须由标准机构或独立评测方在申报和系统冻结前发布，并且只能收紧参考标准；申请者自定义配置不得产生 L5 认证 |
| L5 参考域 | AI-L5 的运行域必须覆盖标准版本规定的 $D_{\mathrm{AGI}}^{\mathrm{ref}}$，不得以自选狭窄运行域获得 L5 |
| L5 任务侧资源 | 信息、工具、最低权限和人类参照资源由认证配置给定，申请者不得以缩减这些条件排除困难任务 |
| 系统冻结点 | 必须在保密评测前冻结模型、系统提示、工具配置和系统级学习机制；评测中只允许系统在登记预算内自主适应 |
| 保密留出 | AI-L3 及以上必须包含开发者不可见的任务生成器；AI-L4 及以上必须包含任务族或领域留出；AI-L5 必须包含多个按差异准则选取的独立新领域，核心实例在系统冻结后由隐藏随机种子生成 |
| 防污染 | 必须记录训练数据治理、评测保密方式和污染检测结果 |
| 无专项改造 | 评测开始后不得为单个测试任务进行开发者专项训练、提示工程或代码修补 |
| 资源计量 | 必须计入模型调用、工具、检索、人工帮助、交互和失败重试 |
| 退出计分 | 合法排除任务的正确退出计入退出指标；对运行域内可行任务的拒绝不得计作完成 |
| 排除裁定 | 排除条件必须在抽样前登记，并由独立评测方判定；系统自身算力、时间或能力不足不构成 L5 任务排除理由 |
| 风险分层 | 高风险任务必须单独报告，不能被大量低风险任务平均 |
| 覆盖分层 | 强制层、交叉层、抽样权重和最低样本量由独立评测方预先冻结；每层必须分别通过，任一层失败即失败 |
| 可复核性 | 必须公开足以复核的任务定义、评分器、日志结构、统计方法和置信区间 |
| 版本化 | 模型、工具、系统提示、记忆、权限或运行域发生实质变化后，等级证书必须更新版本 |
| 降级规则 | 任一必选门不通过时，最终等级降到全部门均通过的最高等级 |

标准报告模板如下。

| 字段 | 填写内容 |
|---|---|
| 系统与版本 | 模型、代理框架、工具、记忆和策略版本 |
| 申请等级与证据 | $\mathrm{AI\text{-}L}\ell@D/\mathrm{A}k$ |
| 智能运行域 | $\mathcal T,\mathcal E,\mathcal M,\mathcal H,\mathcal B,\mathcal P$ 的完整说明 |
| 排除范围 | 无解、不可观测、越权、超预算及其他排除条件 |
| 任务与环境留出 | 未见实例、任务族、领域和生成器的构造方式 |
| 数值门槛 | $\delta,\gamma,\mathbf B_{\mathrm{adapt}},G_{\mathrm{transfer}},\iota,\kappa,s_{\mathrm{exit}},r_{\mathrm{sev}},H,a$ |
| 人类参照 | 人群资格、样本量、资源、时间和非劣界 |
| 结构性证书 | 若提供，分别报告 $\epsilon_z^*(S),\epsilon_z^{\mathrm{act}}(S),\rho_\ell$、上下文是否可见及所用复杂度指标 |
| 安全与审计 | 权限控制、退出机制、严重失败测试和日志完整性 |
| 最终结论 | 通过等级、未通过项目、证书适用范围与有效期 |

## 11. 证据保证等级

能力等级 $\mathrm{L}\ell$ 与证据等级 $\mathrm{A}k$ 相互独立。高能力主张不能自动获得高证据等级，精确闭合的数学证明也不能替代真实系统的任务与安全评测。

| 证据等级 | 名称 | 累积要求 |
|---|---|---|
| **A0** | 未验证声明 | 只有系统提供者的描述，没有独立、可复现的评测 |
| **A1** | 可复现实证 | 固定协议、公开评分方法和可复现实验；报告运行域、资源和分组结果 |
| **A2** | 统计保证 | 满足 A1，并给出保密留出、覆盖分层、压力测试、置信区间、尾部失败和分布稳健结果 |
| **A3** | 结构证明 | 满足 A2，并在有限代理或其他明确模型上给出闭合、复杂度或安全性质的形式证明，同时计入代理模型到真实系统的扰动误差 |
| **A4** | 端到端域内认证 | 满足 A3，并由独立机构对系统冻结、数据治理、资源计量、任务性能、严重风险、审计和持续监测进行完整认证 |

AI-L5 的正式认证至少必须达到 A2。A0 或 A1 系统只能标记为“AI-L5 候选”，不得直接标记为已认证 AGI。

## 12. 最短定义

$$
\boxed{
\begin{array}{c}
\mathrm{AI\text{-}L1\text{—}L4}:
\text{从固定任务工具逐级扩展到开放域自主智能体};
\\[2mm]
\mathrm{AI\text{-}L5/AGI}:
\text{在广泛人类可操作域内，以有界成本学习未预枚举任务，}\\
\text{跨域迁移并长期自主行动，同时维持可量化的可靠性与安全边界。}
\end{array}
}
$$
