# 范畴论与 Transformer 分析

**一句话：Transformer = 固定语义空间（W）+ 动态路由（A）。W 训练后固定、可复合、存知识；A 每层重算、不可复合、做路由。两者被残差流的 I+G 结构绑在一起——不是因果关系，是同源并行的两个结构后果。**

---

## 框架

残差流状态是位置和内容的张量积：

$$|\Psi\rangle = \sum_i |i\rangle \otimes |x_i\rangle, \quad |i\rangle \in \mathbb{R}^n \text{（位置）}, \quad |x_i\rangle \in \mathbb{R}^d \text{（内容向量）}$$

算子分两类，各自作用在各自的因子上，互不干涉：

$$(A \otimes I)(I \otimes W) = A \otimes W = (I \otimes W)(A \otimes I)$$

| | W（权重） | A（注意力分数） |
|---|---|---|
| **作用域** | $\mathbb{R}^d$（内容因子） | $\mathbb{R}^n$（位置因子） |
| **变化** | 训练后固定 | 每层重算 |
| **复合** | 可跨层复合（矩阵乘法封闭） | 不可跨层复合（CK 不成立） |
| **存什么** | 语义知识 | 路由决策 |
| **包含** | $W_Q, W_K, W_V, W_O$, MLP 权重, $E, U$ | softmax 输出的 $n \times n$ 分数矩阵 |

常说的"注意力机制"按此切分被纵向剖开：QKV 投影矩阵属于 W（固定、存语义），softmax 输出的 $a_{ij}$ 属于 A（动态、做路由）。切分的标准是**变/不变**，不是功能模块。

**一层前向**：

$$|\Psi'\rangle = |\Psi\rangle + (A \otimes W_O W_V)|\Psi\rangle + (I \otimes \text{MLP})|\Psi\rangle$$

$$a_{ij} = \text{softmax}\!\left(\frac{\langle x_i|W_Q^\top W_K|x_j\rangle}{\sqrt{d}}\right)_j \quad \leftarrow\; \text{W 提供匹配知识，A 产出路由决策}$$

**核心论断**：语义存在 W 里，不在 token 里。$|x_i\rangle$ 携带的"语义"完全由 W 编码——关掉 W，它退化为无意义数值。$|x_i\rangle$ 是路由状态：路由系统在语义空间中的当前落脚点。

**$|x_i\rangle$ 的架构混淆**：同一个向量同时服务语义变换（被 W 做 MLP、$W_V W_O$）和路由判断（被 A 做 $Q \cdot K^T$）。语义需要高维稠密表征，路由需要低维结构化信号——两者需求冲突，混在同一向量中是架构缺陷。最简修复：分出独立路由维度 $d_r$，路由信号不过 MLP。（详见[讨论记录-改进方向](讨论记录-改进方向.md)）

## 五个命题

| # | 命题 | 状态 | 详细 |
|---|---|---|---|
| 1 | **A 不可跨层复合（CK 不成立）**。$A^{(l+1)}$ 依赖完整坐标 $X^{(l)} = X^{(l-1)} + G_l(X^{(l-1)})$，不由 $A^{(l)}$ 单独决定。代数乘积 $A^{(l+1)}\! \cdot A^{(l)}$ 不等于实际的两步路由。 | $\blacksquare$ 严格 | [§2](完备证明.md#2-a-不可跨层复合ck-不成立) |
| 2 | **若 A 可复合则路由退化（Perron-Frobenius）**。时齐全正 $A$ 的幂收敛到秩一矩阵——所有 token 获得相同注意力上下文，推理路径无区分。 | $\blacksquare$ 严格 | [§3](完备证明.md#3-若-a-可复合路由退化perron-frobenius) |
| 3 | **W 与 A 结构耦合，非因果**。$I+G$ 的 $I$ 保留历史 → 坐标每层不同 → A 重算（即使 $W=I$）；$G_l$ 中的 W 矩阵封闭 → W 可复合。同根两根枝。 | $\blacksquare$ 综合 | [§4](完备证明.md#4-w-与-a-的结构耦合) |
| 4 | **语义簇正反馈——簇内角非分化，分化侧概要级**。簇内：注意力重叠 + 窄锥 → 更新向量夹角受控，余弦相似度不分化。簇外分化需额外验证。 | $\blacksquare$ 部分 | [§5](完备证明.md#5-语义簇正反馈的动力学基础) |
| 5 | **I+G 分解 → $2^L$ 条路径**。$F_l = I + G_l$。残差加法是深度有意义的前提——覆盖模式使路径坍缩为 1。 | $\blacksquare$ 严格 | [§6](完备证明.md#6-ig-分解与路径展开) |

## 可检验预测

| # | 预测 | 检验方式 |
|---|------|----------|
| 1 | 相似 token 更新向量夹角随层受控 | 逐层测 $\sin\phi_v \leq 2\eta M/((1-\eta)m)$ |
| 2 | $\lambda_{\max} \approx 0$ | 逐层 Jacobian 谱 |
| 3 | 残差系数 $\varepsilon \to 0$ 则坍缩 | $|x\rangle + \varepsilon \cdot (\text{Attn} + \text{MLP})$ |
| 4 | A 固定 → 退化 | 参数共享 + CK 损失 |
| 5 | 路由信号低维 | 探针：从 $|x_i\rangle$ 预测 $a_{i*}$ 的有效秩 ≪ 语义探针 |
| 6 | 深层路由退化先于语义退化 | $\text{KL}(a_i^{(l)} \| a_i^{(l-1)})$ 趋零，但 $\|\Delta x_i^{(l)}\|$ 持续非零 |
| 7 | $d_{\text{head}}$ 增大边际收益递减 | $d_{\text{head}} \in \{32, 64, 128, 256, 512\}$，路由信号已被低维捕获 |
| 8 | $L \times H$ 不变时 $L/H$ 偏移影响推理质量 | 存在最优 $L$（步数）和最优 $H$（$d_k \approx 32$ 阈值），偏离则 ppl 下降 |
