\title{\bfseries 宏观规律何时存在？\\[0.35em]
\Large 有限随机系统中的压缩—闭合判据\\[0.8em]
\normalsize \textit{When Do Macroscopic Laws Exist? A Compression--Closure Criterion for Finite Stochastic Systems}}
\author{石琛}
\date{}

\begin{document}
\maketitle

\begin{abstract}
本文研究一个边界明确的有限状态问题：给定任务、微观观测和允许的 Markov 动力学，何时能够把大量微观状态归并为较少的宏观状态，同时保留任务并使宏观状态近似自行演化？我们首先用稳定分区细化构造对严格冗余不变的可辨微观空间。在经典 lumpability 与行为最小化理论给出的最粗精确商基础上，本文定义允许误差时实际达到的复杂度--闭合误差前沿。对增长系统族，我们进一步定义只依赖任务分区和纤维预测分歧的指标 $\Gamma_N$，并由半径--直径夹逼证明：$\Gamma_N\to0$ 等价于存在同一列任务保真表示，其相对状态数与最优最坏行闭合误差同时趋零。置换对称故障--修复系统的完整前沿给出 $\Gamma_N=\min\{1/N,(N+1)/2^N\}\to0$；向该核族加入一个趋于零的逐部件异质纯修复扰动，会使每个有限规模的精确任务商退化为离散分区，却仍保持 $\Gamma_N\to0$，从而展示近似理论相对于精确商的必要性；单点标记循环链则满足 $\Gamma_N=1$。正文还给出任务充分性与群对称两类结构证书，并明确讨论时间尺度和可辨基线的稳健性边界；其余扩展作为条件式接口置于附录。

\medskip
\noindent\textbf{关键词：}Markov 粗粒化；状态压缩；宏观闭合；任务保真；压缩—闭合判据；lumpability；预测状态
\end{abstract}

\begin{center}
\begin{minipage}{0.94\textwidth}
\small
\textbf{English abstract.}
We ask when a family of finite stochastic systems admits a task-relative, low-complexity macroscopic law. Exact observational and dynamical redundancies are first removed by stable partition refinement. Taking the classical coarsest exact lumping as the zero-error endpoint, we define an attained complexity--closure-error frontier and an explicit index $\Gamma_N$ that requires no prespecified macroscopic transition kernel. A radius--diameter sandwich shows that $\Gamma_N\to0$ if and only if one sequence of task-preserving quotients has both vanishing relative state count and vanishing optimized worst-row one-step closure defect. A permutation-invariant fault--repair family has the exact value $\Gamma_N=\min\{1/N,(N+1)/2^N\}$. Adding a vanishing componentwise heterogeneous pure-repair perturbation makes the exact task quotient discrete at every finite size while preserving $\Gamma_N\to0$, demonstrating a genuinely approximate regime; a marked cycle instead has $\Gamma_N=1$. We also give structural certificates based on task sufficiency and group symmetry and state explicitly the time-scale and baseline-stability limits of this one-step criterion. Further extensions are presented only as conditional interfaces.
\end{minipage}
\end{center}
